# دار الأذكار

تطبيق ويب بسيط لأذكار الصباح والمساء والنوم، يعمل بدون إنترنت ويمكن تثبيته على الموبايل كتطبيق (PWA).

من إعداد [دار الإسلام والتقنية](https://darislamtech.com).

## التشغيل

- افتح الموقع المنشور من المتصفح، أو شغّل خادماً محلياً داخل المجلد مثل:
  `python -m http.server 8000` ثم افتح `http://localhost:8000`.
- فتح `index.html` مباشرة كملف يعمل أيضاً، لكن خاصية العمل بدون إنترنت والتثبيت تحتاج تشغيله من خادم (https أو localhost).

## التثبيت على الموبايل

- **أندرويد (كروم):** اضغط زر «تثبيت التطبيق» أعلى الصفحة، أو من قائمة المتصفح اختر «تثبيت التطبيق».
- **آيفون (سفاري):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد أول فتح يتم حفظ كل الملفات على الجهاز، فيعمل التطبيق بعدها بدون إنترنت.

## المميزات

- تبويبات للأذكار: الصباح، المساء، النوم.
- عداد تكرار لكل ذكر.
- نسبة إنجاز للقسم الحالي.
- حفظ التقدم محلياً في المتصفح.
- زر لإعادة ضبط تقدم القسم الحالي.
- يعمل بدون إنترنت (Service Worker) والخط محفوظ داخل المشروع.
- قابل للتثبيت على الموبايل مع أيقونة خاصة.

## ملاحظة للتطوير

عند تعديل أي ملف، غيّر رقم الإصدار في `CACHE_NAME` داخل `sw.js` حتى تصل التحديثات للأجهزة التي ثبّتت التطبيق.
